OneCast 1.0.0（Windows x64 便携版）

一、先解除「来自 Internet」锁定（重要，只需做一次）
原因：从网上下载的文件会被 Windows 打上「来自 Internet」标记，双击 exe 时
      SmartScreen 会弹「Windows 已保护你的电脑」。这与代码签名无关，解除即可。

方法 A（推荐，连压缩包一起处理）
  1. 先不要解压。右键下载到的 OneCast-win64.zip → 属性
  2. 勾选底部的「解除锁定」→ 确定
  3. 再解压，解压出来的文件就没有标记了

方法 B（已经解压了）
  1. 进入解压后的文件夹，双击「一键解除锁定.bat」
  2. 让脚本跑完（无管理员权限也可），关闭窗口
  3. 或者手动：右键 OneCast.exe → 属性 → 勾选「解除锁定」→ 确定

二、运行
1. 把整个文件夹解压到任意位置，例如 D:\OneCast
2. 双击 OneCast.exe，无需安装、无需联网

三、桌面图标
1. 右键 OneCast.exe → 发送到 → 桌面快捷方式
2. 右键桌面快捷方式 → 属性 → 更改图标 → 浏览，选择文件夹内的 onecast.ico

四、数据存在哪里
账号、设置、审计日志、加密后的凭证都保存在本机
%APPDATA%\OneCast\（localStorage 与 window-state.json）。
卸载即删除该文件夹，不留残余。

五、说明
- 默认开启「零成本模式」：不调用任何平台 API，只生成文案并打开各平台创作中心
- 凭证加密使用 Web Crypto（PBKDF2-SHA256 + AES-GCM-256），主密码不落盘
- 平台创作中心一律用系统默认浏览器打开，不在应用内跳转
- 本程序未购买代码签名证书（个人开发者无法申请 OV/EV），故首次运行需按第一节解除锁定
