OneCast 1.0.6（Windows x64 便携版）

一、下载（需要先开代理）
1. 先打开 F:\VPN\clash-verge.exe（连不上 GitHub 时必须开着它）
2. 再到 https://github.com/lssqian777-source/132465/releases 下载最新的 OneCast-win64.zip
3. 建议解压到桌面：右键 zip → 全部解压 → 位置选「桌面」→ 得到桌面上的 OneCast 文件夹

二、先解除「来自 Internet」锁定（重要，只需做一次）
原因：从网上下载的文件会被 Windows 打上「来自 Internet」标记，双击 exe 时
      SmartScreen 会弹「Windows 已保护你的电脑」。这与代码签名无关，解除即可。

方法 A（推荐，连压缩包一起处理）
  1. 先不要解压。右键下载到的 OneCast-win64.zip → 属性
  2. 勾选底部的「解除锁定」→ 确定
  3. 再解压，解压出来的文件就没有标记了

方法 B（已经解压了）
  1. 进入解压后的文件夹，双击「一键解除锁定.bat」
  2. 让脚本跑完（无管理员权限也可），关闭窗口
  3. 或者手动：右键 OneCast.exe → 属性 → 勾选「解除锁定」→ 确定

方法 C（Windows 11 弹「智能应用控制」拦截时）
  右键「安装证书并签名.bat」→ 以管理员身份运行，等提示「签名成功」
  如果还是被拦：Windows 安全中心 → 应用和浏览器控制 → 智能应用控制设置 → 关闭

三、运行
1. 双击 OneCast.exe，无需安装
2. 界面更新自动进行：开着 Clash 时软件会静默下载最新界面，下次打开自动生效，
   不会弹任何窗口。Clash 没开也能正常用，只是不更新界面。

四、桌面图标
1. 右键 OneCast.exe → 发送到 → 桌面快捷方式
2. 右键桌面快捷方式 → 属性 → 更改图标 → 浏览，选择文件夹内的 onecast.ico

五、数据存在哪里
账号、设置、审计日志、加密后的凭证都保存在本机
%APPDATA%\OneCast\（localStorage 与 window-state.json）。
换文件夹 / 删掉旧文件夹不影响数据；卸载即删除该文件夹，不留残余。

六、说明
- 默认开启「零成本模式」：不调用任何平台 API，只生成文案并打开各平台创作中心
- 所有平台默认「手动 / 半自动」：填个账号昵称就能用，不需要任何 Token
  想用官方 API 自动发布时，再在账号设置里改成 OAuth 并填 Token（存入加密保险箱）
- 上传的素材和封面会保存在本机素材库，重启后自动恢复；点击素材缩略图可预览大图
- 凭证加密使用 Web Crypto（PBKDF2-SHA256 + AES-GCM-256），主密码不落盘
- 平台创作中心一律用系统默认浏览器打开，不在应用内跳转
- 本程序未购买代码签名证书（个人开发者无法申请 OV/EV），故首次运行需按第二节处理
