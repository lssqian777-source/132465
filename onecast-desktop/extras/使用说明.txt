OneCast 1.0.7（Windows x64 便携版）

一、下载（需要先开代理）
1. 先打开 F:\VPN\clash-verge.exe（连不上 GitHub 时必须开着它）
2. 到 https://github.com/lssqian777-source/132465/releases 下载最新版：
   OneCast-1.0.7-portable.exe（单个文件，约 72 MB）
3. 建议放到桌面：把 exe 拖到桌面即可。它不用安装，双击就能跑。

二、先解除「来自 Internet」锁定（重要，只需做一次）
原因：从网上下载的文件会被 Windows 打上「来自 Internet」标记，双击时
      SmartScreen 会弹「Windows 已保护你的电脑」。这与代码签名无关，解除即可。

  1. 右键 OneCast-1.0.7-portable.exe → 属性
  2. 勾选底部的「解除锁定」→ 确定
  3. 再双击运行

被 Windows 11「智能应用控制」拦截时：
  Windows 安全中心 → 应用和浏览器控制 → 智能应用控制设置 → 关闭

三、运行
1. 双击 OneCast-1.0.7-portable.exe，无需安装
   （首次启动会在 %TEMP% 里解压一次，稍慢，属正常）
2. 界面更新自动进行：开着 Clash 时软件会静默下载最新界面，下次打开自动生效，
   不会弹任何窗口。Clash 没开也能正常用，只是不更新界面。

四、桌面图标
1. 右键 exe → 发送到 → 桌面快捷方式
2. 想换图标：右键快捷方式 → 属性 → 更改图标 → 浏览，选 extras 里的 onecast.ico

五、三种发布方式（设置 → 发布方式）
1. 手动 / 半自动（默认，零风险）
   点发布后生成「发布包」：复制文案 → 打开创作中心 → 你自己粘贴、选图、点发布。
2. 实验性自动发布（推荐先小号试，默认关闭）
   设置里打开「实验性自动发布」后，发布弹窗会多出「执行方式」下拉：
   - 只自动填表：自动上传素材 + 填标题正文，最后一步「发布」仍由你点（默认）
   - 自动填表并提交：连发布按钮也帮你点（风险最高，账号可能被平台限流/封禁）
   - 生成发布包：回到第 1 种方式
3. 官方 API（需平台开放资质，个人一般拿不到，走第 1、2 种即可）

六、自动发布怎么用（第一次必须做登录）
1. 设置 → 实验性自动发布 → 点「打开自动发布工作台」
2. 会弹出一个独立的浏览器窗口（用的是你本机已装的 Chrome 或 Edge）
   在这个窗口里分别登录抖音、小红书等平台，登录态会长期保留。
   注意：它用独立配置目录，不会读取你日常浏览器的 Cookie 和密码。
3. 回到主界面填好文案、上传图片/视频 → 点发布 → 选「只自动填表」先试一次。

已知限制（诚实说明）
- 微信视频号 / 朋友圈没有网页发布入口，只能用半自动，引擎会自动跳过。
- Instagram 网页版发文能力有限，建议手动。
- 平台页面随时改版，自动填表可能对不上位置；失败时会把截图存到
  %APPDATA%\OneCast\automation-logs\，可据此判断卡在哪一步。
- 自动发布违反部分平台的「机器发布」条款，请自行权衡，建议先用小号验证。

七、数据存在哪里
账号、设置、审计日志、素材库、加密后的凭证都保存在本机
%APPDATA%\OneCast\（含 browser-profile 与 automation-logs 两个子目录）。
换文件夹 / 删掉 exe 不影响数据；彻底卸载就删除该文件夹，不留残余。

八、安全说明
- 凭证加密使用 Web Crypto（PBKDF2-SHA256 310000 次 + AES-GCM-256），主密码不落盘
- 渲染层全程 sandbox + contextIsolation，外链一律交给系统浏览器
- 平台创作中心不会在应用内跳转；自动发布在独立浏览器配置里运行，不碰你的日常登录
- 本程序未购买代码签名证书（个人无法申请 OV/EV），故首次运行需按第二节解除锁定
